## 3. Доработка индивидуального проекта

Создан общий каталог `templates/`, подключённый через `TEMPLATES[0]["DIRS"]`.
Шаблоны приложений размещены в `homepage/templates/homepage/`,
`catalog/templates/catalog/` и `taxonomy/templates/taxonomy/`.

Базовый `templates/base.html` содержит HTML-каркас, подключения статики,
основной контейнер и подвал. Дочерние страницы используют `extends` и блоки
`title`, `content`. Через `include` подключаются общая навигация, карточки идей
и категорий, а также единый фрагмент статуса идеи.

Представления вызывают `render(request, template, context)`. В контекст передаются
списки и объекты `Idea`, `Category`, сведения о количестве свободных идей и
дата создания. Подсчёт и отбор данных выполняются в Python, а вывод — в шаблонах.
Функция `page()` и прежний модуль `web_page.py` удалены.

Для коллекций используются `for` и `empty`; для статусов «Свободна»/«Взята»,
отсутствующей категории и активной навигации — `if`. Автоматическое экранирование
Django защищает вывод текстовых значений. Фильтры `length`, `default`, `date`,
`truncatechars`, `linebreaksbr` форматируют реальные данные проекта.

В маршрутах объявлены `app_name` и пространства имён `homepage`, `catalog`,
`taxonomy`. Ссылки формируются тегом `url`, включая числовые идентификаторы.
Собственный `static/css/site.css` сохранён и используется в интерфейсе.
Через `load static` и `static` подключены логотип `homepage/img/logo.svg`
и JavaScript `homepage/js/main.js`, обновляющий текущий год в подвале.

## 4. Результат работы

Реализованы пять основных страниц: `/`, `/ideas/`, `/ideas/<id>/`,
`/categories/`, `/categories/<id>/`. Сохранены дизайн и переходы между ними.
Для отсутствующих объектов возвращается HTTP 404 с шаблоном приложения;
неизвестные маршруты при `DEBUG=False` используют общий шаблон `404.html`.

Объекты загружаются из существующих JSON-файлов через `storage.py` и
`web_data.py`. Консольный интерфейс и бизнес-логика сохранены. Django ORM для
предметной области и веб-формы не добавлялись. Текст обновления README подготовлен
отдельно в `docs/pr6-readme-section.md`; сам README по просьбе автора не изменён.
