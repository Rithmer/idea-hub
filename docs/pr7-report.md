## 3. Структура базы и импорт

Создана база предметной области data/idea_hub.sqlite и схема sql/schema.sql.
Основные сущности представлены тремя таблицами:

- categories: id INTEGER PRIMARY KEY, name TEXT NOT NULL UNIQUE.
- users: id INTEGER PRIMARY KEY, name TEXT NOT NULL UNIQUE, password TEXT NOT NULL, is_admin INTEGER NOT NULL DEFAULT 0.
- ideas: id INTEGER PRIMARY KEY, title/description TEXT NOT NULL, category_id/author_id INTEGER NOT NULL, status TEXT NOT NULL, selected_by_id INTEGER NULL, created_at TEXT NOT NULL.

Внешние ключи связывают идеи с категорией, автором и выбравшим пользователем.
CHECK проверяет статус, его согласованность с selected_by_id и значения 0/1
для is_admin. Частичный уникальный индекс запрещает выбор нескольких идей
одним пользователем. Дата хранится в формате YYYY-MM-DD; NULL допускается
для отсутствующего выбора свободной идеи.

Модуль db/database.py создаёт соединения sqlite3.connect(), включает
PRAGMA foreign_keys = ON и sqlite3.Row. Схема применяется отдельно от ORM.
Скрипт db/import_json.py использует executemany(), параметры ? и commit().
При ошибке выполняется rollback всей транзакции; повторный импорт обновляет
записи с теми же ID без дублирования. Перенесены 5 категорий, 5 пользователей
и 4 идеи. JSON-файлы, предметные классы и консольная версия сохранены.

## 4. SQL-запросы и веб-интерфейс

В sql/queries.sql разработано 17 запросов с комментариями. Модуль db/queries.py
выполняет непосредственно эти команды; результаты передаются в контекст шаблонов.

Перечень: categories, users, ideas, idea_detail, filtered_ideas, available_ideas,
selected_ideas, category_detail, category_ideas, idea_totals, user_totals,
category_statistics, author_statistics, popular_categories, status_statistics,
recent_ideas, filtered_count.

Выполнено требование «не менее 10 запросов, по два каждого вида»: списки
categories/users; WHERE filtered_ideas/available_ideas; JOIN ideas/idea_detail;
агрегаты idea_totals/user_totals; GROUP BY category_statistics/author_statistics.
Дополнительно используются HAVING, ORDER BY, LIMIT, OFFSET, COUNT, SUM, MIN, MAX.

Сценарии сайта: каталог с поиском по названию, языку, автору и статусу;
сортировка и пагинация; поиск свободных идей; просмотр выбранных проектов;
список авторов; статистика по языкам, авторам и статусам; фильтрация категорий
по минимальному числу идей. Работают главная и страницы отдельных идей/категорий.
Все 17 запросов используются веб-интерфейсом. Ввод передаётся через параметры ?,
внутренние ссылки используют именованные URL. Неверный ввод даёт 400,
отсутствующие объекты — 404; пустые результаты обработаны шаблонами.

Пример поиска Roomly адаптирован к IdeaHub: доступность идеи определяется
текущим статусом, а условия поиска — языком и названием, без бронирования на дату.
Веб-часть читает SQLite; JSON остаётся источником явного импорта и консольной версии.
README по прямому указанию автора не изменён. Описание слоя базы данных находится
в docs/pr7-database.md, результаты SQL CLI — в docs/pr7-sql-results.md.
