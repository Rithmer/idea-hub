# IdeaHub

IdeaHub — веб-приложение для поиска и выбора идей для программных проектов.

Пользователь может просматривать каталог, находить идеи по языку программирования
и выбирать свободную идею. После выбора идея закрепляется за пользователем
и становится недоступной для других участников сервиса.

---

## О проекте

Поиск идеи для нового проекта часто занимает больше времени, чем сама подготовка к разработке. 

Idea-hub объединяет идеи для проектов на разных языках программирования в едином каталоге и упрощает поиск и выбор подходящей проектной идеи.

---

## Целевая аудитория

Idea-hub ориентирован на:

- студентов, выбирающих тему для учебного или индивидуального проекта;
- начинающих разработчиков, которые хотят получить практический опыт;
- разработчиков, ищущих идею для pet-проекта;
- пользователей, желающих подобрать проект под конкретный язык программирования.

---

## Предметная область

Основой сервиса является **каталог проектных идей**.

Каждая идея содержит название, описание, категорию и текущий статус.

Категория определяет язык программирования, с которым связана проектная идея.
Например:

- Python;
- Java;
- JavaScript;
- C#;
- Go.

Статус показывает, доступна ли идея для выбора:

- `Не взята` — идея свободна;
- `Взята` — идея закреплена за пользователем.

Пользователь может найти подходящую идею в каталоге, открыть её страницу
и посмотреть подробную информацию.

Если идея имеет статус `Не взята`, пользователь может выбрать её.
После выбора идея закрепляется за пользователем, а её статус изменяется на `Взята`.

---

## Основные сущности

### Idea

Основная сущность проекта. Представляет идею программного проекта.

Содержит:

- уникальный идентификатор;
- название;
- описание;
- категорию;
- статус;
- пользователя, выбравшего идею;
- дату создания.

---

### User

Зарегистрированный пользователь сервиса.

Пользователь может:

- просматривать каталог;
- искать идеи;
- фильтровать идеи;
- просматривать подробную информацию;
- выбирать свободную идею;
- просматривать выбранную им идею.

---

### Category

Категория используется для классификации идей по основному языку программирования.

Примеры категорий:

- Python;
- Java;
- JavaScript;
- C#;
- Go.

---

### Status

Определяет текущее состояние идеи.

Основные значения:

| Статус     | Описание                             |
| ---------- | ------------------------------------ |
| `Не взята` | Идея свободна и доступна для выбора  |
| `Взята`    | Идея уже закреплена за пользователем |

## Возможности

### Каталог идей

* просмотр списка проектных идей;
* просмотр подробной информации об идее;
* отображение категории;
* отображение текущего статуса;
* отображение доступности идеи.

### Поиск и фильтрация

* поиск идеи по названию;
* фильтрация по языку программирования;
* фильтрация по статусу;
* просмотр только свободных идей.

### Выбор идеи

* проверка доступности идеи;
* выбор свободной идеи;
* закрепление идеи за пользователем;
* автоматическое изменение статуса на `Взята`;
* просмотр выбранной пользователем идеи.

### Пользователи

* регистрация;
* авторизация;
* выход из аккаунта;
* просмотр профиля;
* просмотр выбранной идеи.

### Управление контентом

Администратор сможет:

* добавлять идеи;
* редактировать идеи;
* удалять идеи;
* создавать категории;
* редактировать категории;
* изменять статус проектной идеи;
* просматривать пользователей.

## Roadmap

### Этап 1 — Базовый каталог идей

* поиск идей по названию;
* отображение названия и описания идеи;
* добавление категорий;
* добавление статусов «Не взята» и «Взята»;
* просмотр подробной информации об идее.

### Этап 2 — Поиск и фильтрация

* создание каталога проектных идей;
* фильтрация идей по языку программирования;
* фильтрация по статусу;
* отображение только свободных идей;
* сортировка списка идей.

### Этап 3 — Пользователи

* регистрация пользователей;
* авторизация;
* выход из аккаунта;
* создание профиля пользователя;
* просмотр информации о собственном аккаунте.

### Этап 4 — Выбор проектной идеи

* возможность выбрать свободную идею;
* закрепление идеи за пользователем;
* автоматическое изменение статуса идеи на «Взята»;
* отображение пользователя, за которым закреплена идея;
* запрет выбора уже занятой идеи;
* просмотр выбранной пользователем идеи.

### Этап 5 — Управление проектными идеями

* добавление новых идей;
* редактирование существующих идей;
* удаление идей;
* управление категориями;
* изменение статуса проектной идеи;
* проверка корректности вводимых данных.

### Этап 6 — Личный кабинет

* отображение выбранной проектной идеи;
* просмотр информации о ней;
* возможность отказаться от выбранной идеи;
* изменение статуса идеи обратно на «Не взята».

### Этап 7 — Администрирование

Администратор сможет:

* просматривать список пользователей;
* добавлять и редактировать проектные идеи;
* удалять некорректные или устаревшие идеи;
* управлять категориями;
* управлять статусами;
* просматривать занятые и свободные идеи.
